# Technique Index

The active skill chooses a response path from what the caller actually says. It does not force a script.

| Situation | Procedure | Reference |
|---|---|---|
| Cold or lightly qualified caller | Ask permission, discover the current process, quantify only caller-provided values, and offer a relevant next step | `research-survey.md` |
| Caller has already seen a demo or working prototype | Use the customer-journey mirror only when it helps them reflect on their own process; stop if it feels forced | `customer-journey-mirror.md` |
| Caller asks for price or proof first | Answer from the loaded pitch, qualify fit, and do not bury or fabricate numbers | `SKILL.md` and `live-call-quality.md` |
| Caller already has a solution | Understand coverage and gaps before comparing; never badmouth the incumbent | `live-call-quality.md` |
| Caller needs a person now | Offer an approved transfer or a truthful callback path; never promise an unavailable escalation | `live-call-quality.md` |
| Caller opts out or ends the conversation | Honor the signal, say the required closing, end the provider call, and record the terminal outcome | `SKILL.md` |

The runtime agent loads `voice-ai-cold-calling-research-first`; provider mechanics remain in `apps/agent/agent/skills/voice-calling.md`. Historical platform and brand-specific notes in this directory are not active instructions.
